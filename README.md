# FileFormatProBot 📁

A powerful Telegram bot for converting files between different formats.

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/your-template)

## ✨ Features

### 🖼️ Image Conversion
- JPEG, PNG, WebP, GIF, TIFF, BMP, ICO
- Batch processing support
- Quality adjustment options

### 📄 Document Conversion
- PDF ↔ DOCX ↔ TXT ↔ HTML ↔ ODT ↔ RTF
- Text extraction from PDFs and DOCX
- Document formatting preservation

### 🎵 Audio Conversion
- MP3, WAV, OGG, FLAC, M4A, AAC
- Bitrate and sample rate control
- Audio trimming capability

### 🎬 Video Conversion
- MP4, MKV, AVI, WEBM, MOV, FLV
- Resolution and quality settings
- Frame extraction

### 📦 Archive Processing
- ZIP, RAR, 7Z, TAR, GZ
- Extract individual files
- Compress multiple files

### 📊 Spreadsheet Conversion
- XLSX ↔ CSV ↔ ODS
- Data extraction and formatting
